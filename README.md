A bush-plane rescue run at golden hour: thread all 8 lit rings down Kestrel Valley —
past the river, past Emberwick's lights, under a storm front on the horizon — then land
on the lit runway at Kestrel Field before the fuel runs out. A complete flight game in
plain canvas 2D: throttle and bank discipline, three legs with different goals, fuel
that turns a sortie into decisions, and landings and crashes that read as what happened.

Play it: serve `game/` with any static server (`node serve.ts`, then
http://localhost:8080) and fly with the keyboard and mouse — arrows steer, W/S throttle,
C switches chase/cockpit camera, L toggles the searchlight, P pauses, R restarts.
